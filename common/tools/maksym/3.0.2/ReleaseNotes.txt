        ------------------------
        Release Notes for Maksym
        ------------------------
		
v3.0.2 - 29. oct 2021
---------------------
   * Fixed extraction of data member location (DW_FORM_exprloc).

v3.0.1 - 16. feb 2021
---------------------
   * Fixed the data type extraction for the -TENG option (searching in the .debug_types section).
		
v3.0.0 - 25. jan 2021
---------------------
   * Added the .debug_types section processing in DWARF Debugging Format (for each type defined in a compilation unit, a contribution may be made to a type unit).
   * Removed the XCOFF Debugging Format processing (xcoff_iar_mid8c4d and xcoff_iar_mid996f).
		
v2.58 - 16. nov 2020
--------------------
   * Fixed the difference between symbol address in the symbol table and debug section (name mangling) for Keil ARM Complier (armcc).
		
v2.57 - 31. aug 2020
--------------------
   * Added the list of sections into a metric output.
 
v2.56 - 11. feb 2020
--------------------
   * Fixed parsing the last structure member in a compilation unit.
   
v2.55 - 11. dec 2019
--------------------
   * Fixed missing some symbols for armclamg -lto. The missing address is taken from the symbol table.
   
v2.54 - 5. sep 2019
-------------------
   * Fixed the GetDwarfBaseType() function in dump_elf.c (the type reference can be specified in DW_AT_specification or DW_AT_abstract_origin).		
		
v2.53 - 10. jul 2019
--------------------
   * Fixed parsing structure members in dwarf_keil_mid0028.dll (ARM Compiler 6.12 Tool: armclang).		

v2.52 - 7. mar 2019
-------------------
   * Fixed problem with the compilation unit path, e.g. ../../folder1/../../folder2/file1.h.		

v2.51 - 9. jan 2019
-------------------
   * Updated address calculation of class members in a derived class (_vptr).
   * Added artificial formal parameters to a function signature (a compiler adds a reference to the object for which the function is called as an artificial formal parameter for non-static member functions).
		
v2.50 - 5. dec 2018
-------------------
   * Fixed calculation of addresses of class members in a derived class. The virtual table pointer was not counted (_vptr).
   * Fixed signature version 2008 for pointer to array.
   * Changed the separator '_' to '-' in the 2016 signature data type for -TENG=Register (Sy2 format).
   * Removed Access column and basic data type info from Sy2 format.

v2.49 - 18. jul 2018
--------------------
   * Fixed the termination of reading of members in an abstract data type for some specific cases.
   * Fixed the abstract data type size in its definition for the signature version 2016 (byte size -> bit size).
   * Added the new additional option "-SIGNVER 2008F" to generate the "F" signature for the float data type ("D", "LD" for double, long double). Now there are "-SIGNVER {2008|2016|2008F}".

v2.48 - 18. jun 2018
--------------------
   * Added a new command line option -SWREV.
   * Added the sh_offset member to the _CommonSection structure.
   * Fixed a value of the is_const attribute for -PSYD option.
     The typedef_type element is not generated and his child element didn't copy the value of the is_const attribute.

v2.47 - 31. aug 2017
--------------------
   * Fixed the signature for typedef void MyType. The previous assumption was wrong.
   * If a type specifier in not specified in a typedef the default type is int. The DW_TAG_typedef is without DW_AT_type for typedef void MyType.

v2.46 - 28. aug 2017
--------------------
   * Fixed the processing a typedef without a type specifier. E.g. typedef MyType;

v2.45 - 25. jul 2017
--------------------
   * Fixed the signature for the char data type. Used DW_ATE_unsigned_char info if the char data type is default unsigned.

v2.44 - 10. jul 2017
--------------------
   * Added the _Bool built-in data type into the dwarf_gnu_mid0003.dll.
   * Added option "-TREE" to generate the tree strucure of debug information entries. 
   * Fixed generation of the tree structure of debug information entries.

v2.44 Beta 1 - 20. mar 2017
---------------------------
   * Fixed generating class members (functions, data) if a null entry (A chain of sibling entries is terminated by a null entry.) is used instead of a sibling reference.
     E.g. IAR C/C++ Compiler for RL78
   
v2.43 - 2. mar 2017
-------------------
   * Added the new additional option "-SIGNVER {2008|2016}" to generate a new signature of symbols. 
     E.g. maksym -TENG=Register file.elf -SIGNVER 2016 >file.syr
   * Updated the name of an anonymous structure/union by a typedef name. E.g. typedef struct { ... } TypeName;
   * Fixed the number of registered variables for option "-TENG=Register".   
   
v2.43 Beta 5 - 8. feb 2017
--------------------------
   * Updated the generation PSYD. Added data types to structure/union members. Typedefs are ignored.
   
v2.43 Beta 4 - 1. feb 2017
--------------------------
   * Removed forgotted "BREAK".

v2.43 Beta 3 - 31. jan 2017
---------------------------
   * Fixed the generation METRIC=XML. The replacement special characters '<', '>', '&' by predefined entities '&lt;', '&gt;', '&amp;' for functions. It was only for variables.
   
v2.43 Beta 2 - 3. nov 2016
--------------------------
   * Fixed generation of signatures (pointer to void, pointer to volatile void, void was not in DWARF).
   
v2.43 Beta 1 - 12. oct 2016
---------------------------
   * Added the new format of signature (signature_2016) to PSYD. Old atribute "signature" was renamed to "signature_2008".
   * Added option -OFFSET <value> to add positive value to or subtract negative value from all absolute addresses.
   * Added the wchar_t type.
   * Fixed the generation of symbols with zero address. Symbols which are not in the symbol table are not generated.
   * Fixed the data accessibility (Access in TENG=Register format file).
   * Fixed signature of DW_TAG_enumeration_type (signed, unsigned).
   
v2.42 - 14. jun 2016
--------------------
   * Fixed the termination an inheritance entry which is derived from itself. (iar rx)
   * Fixed the generation class members. The members which have set the flag declaration are not generated. (iar rx)  
   
v2.41 - 15. may 2016
--------------------
   * Fixed the termination embeded structure types comparing sibling references (sibling reference to NULL Debug Information Entry).
   
v2.41 Beta 2 - 10. feb 2016

v2.41 Beta 1 - 22. jan 2016

   * Fixed the generation the members of the anonymous structures. The member identifier (Object0x??) generated by the Maksym is omitted.
   
v2.40 - 11. dec 2015
--------------------
   * Changed the extracting symbols:
     - Symbols with zero address are extracted by default.
     - Unnamed symbols (e.g. anonymous structure, enumaration) are not extracted.
   * Added the processing DW_TAG_class_type, DW_TAG_inheritance. 
     - Generation static member variables and member functions, pattern <Class>_<Member>. 
     - Instance members (also inherited members) are displayed the same way as DW_TAG_structure_type.
     - Overloaded functions are distinguished by adding a list of parameter types as suffic to the name.
   * Added the processing DW_AT_specification and DW_AT_abstract_origin.   
  
v2.39 - 11. nov 2015
--------------------
   * Fixed the generation METRIC=XML. The ELF segments used to calculate memory usage.
   * Fixed the filtering already generated functions for dwarf_keil_mid0028.dll. The member orig_location was added.
   * Fixed the parsing of DW_AT_high_pc. The value of the attribute may be address or constant.
   * Renamed library dwarf_codewarrior_mid004.dll to dwarf_freescale_mid0004.dll and updated tengsio.ini.   
   
v2.38 - 23. sep 2015

   * Fixed the creating an abbreviation table. The size of the table was fixed to 256 rows. Now the size is reallocated as needed.
