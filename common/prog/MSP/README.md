# MSP - Microcontroller Support Package

## 1. Introduction

<br>
The MSP (Microcontroller Support Package) provides the abstraction of cores and peripherals
for all microcontrollers supported by MCU Framework.

<br><br>
## 2. MSP Overview

<br>
The MSP contains:

* [HAL - the Hardware Abstraction Layer Source code](./doc/hal.md)
* [MCAL - the Microcontroller Abstraction Layer code](./mcal/README.md)
* CMSIS - the Common Microcontroller Software Interface Standard for cores Cortex-M supported by MCU Framework
* ArmCMx - the abstraction for ARM Cortex-M MCUs supported by MCU Framework
* PSoC Creator - the project template and BSH components for it
