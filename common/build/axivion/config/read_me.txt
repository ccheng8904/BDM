Version specific document type file for conf-files for diverse Axivion bauhaus suite tools that are maintained by the generic group:
bauhaus_configuration.dtd
This file comes with the Axivion software and is provided by the Axivion installation on the M-Drive.

Version specific files for the local analysis that are maintained by the generic group:
continuous.xml
continuous.dtd
These files come with the Axivion software and are provided by the Axivion installation on the M-Drive.


Project specific files used by the local analysis and the continuous integration for the architecture analysis step that have to be maintained by the project:
Architecture.gxl
Mapping.gxl
Ignore.gxl
The first versions of these files are provided by the project setup (platform specific). Afterwards they shall be maintained by the project.
Attention: if new source files are added they have to be added to the mapping too; otherwise the architecture analysis is not able to work (properly).

Process specific files used by the local analysis for the style check analysis step that are maintained by the generic group:
stylecheck_config.py
stylecheck.config
The file stylecheck_config.py is provided by the generic group (i.e. exported to the project during the project setup).
The file stylecheck.config is generated by the make process according to the specified Axivion version.

Process specific files used for the Axivion build process that are maintained by the generic group:
build.conf
ir2rfg.config
irclones.config
Metrics.config
These files are provided by the generic group (i.e. exported to the project during the project setup).


Generic files that are used for the Axivion build process and that shall only be changed by the generic group:
predefined_sizes.txt
This file is provided by the generic group (i.e. exported to the project during the project setup).
