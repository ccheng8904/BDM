# Misra rules
---

[Rule2.1](./misra2.1.md) A project shall not contain unreachable code.<br>
[Rule2.2](./misra2.2.md) There shall be no dead code.<br>
[Rule2.3](./misra2.3.md)  A project should not contain unused type declarations.<br>
[Rule2.4](./misra2.4.md) A project should not contain unused tag declarations.<br>
