###         make plib example
---


The target creates project library combining all application source files and framework library.

Library will be generated to the `\out\MyVariant\bin` folder.

Run `make plib` target:

```
...
compiling common/prog/firmware_update/version/fwu_version.c
compiling common/prog/firmware_update/mem_drv/com_mal.c
generating out/MyVariant/prog/ped_fw.lib
generating project library out/MyVariant/bin/MyVariant.lib

C:>

```
